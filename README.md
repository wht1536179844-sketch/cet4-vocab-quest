# 四级高频词闯关 · CET-4 Quest

专为手机端碎片时间设计的大学英语四级（CET-4）高频核心词闯关网页。无需后端、零外部依赖，支持本地打开与 PWA 添加到手机主屏幕离线使用。

## 核心功能

- **1,500 个四级阅读真题高频核心词**：直接从 **2026 年 6 月至 2020 年 7 月共 46 套真题（160 篇去重阅读原文 + 40 组选词填空词库）** 中按考频、考期分布与近几年权重剖析提取，分为 **5 大篇章、100 个闯关关卡（每关 15 词）**，每词均标注音标、词性、释义、考频出处（如近 6 年阅读出现次数与最近考期）及双语例句。
- **游戏化闯关模式**：
  - 3 种交替题型：**看词选义**、**看义选词**、**真题语境填空**
  - 4 颗生命值、连击加成（Combo XP）、1-3 星评价、随机 15 词速刷
- **随时打开就能看（口袋词卡）**：
  - 3D 翻转词卡 + 左右滑动切词 + 一键真题发音（Web Speech API）
  - 列表速览模式 + 中英文即时搜索 + 按关卡/掌握状态筛选
- **错题突击本**：答错或手动标红的词自动收录，可一键开启错题闯关清零。
- **离线与桌面化**：支持 `localStorage` 本地自动存档、JSON 导入导出备份、深色模式以及 PWA 添加到手机桌面。

## 如何在手机上“随时打开看”

### 方式 1：同一 Wi-Fi 下手机立刻访问（本地测试）
在项目目录运行任意静态服务器：
```bash
python -m http.server 8080
```
查看电脑局域网 IP（例如 `192.168.1.10`），手机浏览器访问 `http://192.168.1.10:8080` 即可体验。

### 方式 2：免费部署成永久网址（推荐，随时随地可访问）
因为本项目是纯静态网页（HTML/CSS/JS），可直接免费托管：
- **Cloudflare Pages / Vercel / Netlify Drop**：直接拖入整个 `cet4-vocab-quest` 文件夹，1 分钟获得永久 `https://` 网址。
- **GitHub Pages**：推送到 GitHub 仓库后开启 Pages 即可。

获得 `https://` 网址后，在手机浏览器点击 **「分享 / 更多 → 添加到主屏幕」**，即可像原生 App 一样桌面秒开并离线缓存。
